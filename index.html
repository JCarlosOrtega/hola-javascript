Tabla: Conceptos Clave de JavaScript

Concepto Descripción Ejemplo Básico
Variables (let/const) Contenedores para almacenar datos. const es para valores que no cambian. let edad = 30;
Funciones Bloques de código diseñados para realizar una tarea particular. function sumar(a, b) { return a + b; }
DOM **Document Object Model**. La estructura de un documento HTML que JS puede modificar. document.getElementById("id")
Eventos Acciones que ocurren en el navegador (clics, carga de página, etc.) que JS puede detectar. onclick="miFuncion()"
Tipos de Datos Define el tipo de valor que tiene una variable (String, Number, Boolean, Object). "Hola" (String), 42 (Number)
